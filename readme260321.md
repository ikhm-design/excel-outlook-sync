# [Python]PyInstallerでEXE化すると「No module named 'win32timezone'」が出る原因と解決方法

投稿日 2026年03月21日
138 views138 ビュー

## 1. 問題提起
PyInstallerでEXE化したら、
No module named 'win32timezone' が出て困っていませんか？

・ 通常のPython実行では動くのに、EXE化すると落ちる…
・ Python、pyInstaller で アプリを作っている

※Outlook連携をしている方は、このエラーにかなりの確率で遭遇します

<img width="282" height="168" alt="image" src="https://github.com/user-attachments/assets/39103f58-5244-41dc-8e4d-d390d63a4995" />



## 2. 結論
・PyInstaller が pywin32 の依存を検出できないことが原因
pywin32は以下のケースで使われることが多く、OutlookをはじめとしたMS-officeのRPAなどで起きやすい
一覧にするとこのような感じ

<img width="823" height="199" alt="image" src="https://github.com/user-attachments/assets/a7953453-4071-4126-9983-77e2d09fcc2e" />


## 3. なぜ起きるか
PyInstallerは事前にコードを解析して必要なモジュールを収集しますが、
win32comは実行時に必要なモジュールを動的に読み込むため、
両者の仕組みの違いによって今回のエラーが発生します。

<img width="936" height="477" alt="image" src="https://github.com/user-attachments/assets/367f3952-cf78-4b0c-a1f3-af076d49d0b5" />



後出しじゃんけんのイメージに近いかもしれないですね

## 4. 解決方法
対応パターンの紹介です
①、/hidden-import の追加

```
pyInstaller --onefile --hidden-import=win32timezone your_script.py
```

②、強制的にimportしてしまう

```
import win32timezone
```
